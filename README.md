# Data Science, AI & Technology Projects
This repository contains projects focused on data analysis, machine learning, artificial intelligence, cybersecurity, and technology strategy. The projects demonstrate the application of Python, machine learning techniques, analytical methods, and structured decision-making to real-world problems.

## Projects

### Adult Income Classification
A machine learning project examining whether education, race, sex, and relationship status can help classify whether an individual's annual income is above $50,000.
Logistic Regression and Random Forest models were developed and compared using model evaluation, cross-validation, hyperparameter tuning, feature importance, and demographic performance analysis.
**Tools & Methods:** Python • pandas • scikit-learn • Logistic Regression • Random Forest • Cross-Validation • GridSearchCV

### Heart Disease Analysis & Classification
An exploratory data analysis and machine learning project examining demographic and clinical characteristics associated with heart disease using the Cleveland Heart Disease dataset.
The project includes data exploration, visualization, and Logistic Regression classification to identify patterns in the data and evaluate model performance.
**Tools & Methods:** Python • pandas • Matplotlib • scikit-learn • Logistic Regression • Exploratory Data Analysis

### Consequences of Failure to Follow IT Security Policies
An analysis of the organizational risks associated with failing to follow IT security policies, including cybersecurity, financial, legal, and operational consequences.
The project also examines approaches for strengthening security policy compliance through security awareness, leadership involvement, policy communication, employee accountability, and continuous adaptation to evolving threats.
**Focus:** Cybersecurity • IT Security Policies • Security Awareness • Policy Compliance • Risk Management • Data Protection

### NVF Bank AI Strategy Case Analysis
A strategic analysis of how NVF Bank could respond to increasing competition and advances in artificial intelligence while maintaining its human-centered culture.
The project evaluates three AI adoption strategies using a weighted scoring model based on innovation, implementation cost, and strategic alignment. The analysis demonstrates the use of structured decision-making to compare technology alternatives and support an AI implementation recommendation.
**Focus:** Artificial Intelligence • Strategic Analysis • Weighted Scoring Model • Decision-Making • Technology Adoption • Banking
